首らく

アプリ版 1.2

スマホにアプリを入れると、ほかのアプリを開いていても傾きを見守れます。

3ステップ 約1分 Play ストア不要

まず Chrome で開いてください

いまは note などのアプリの中でこのページを見ています。このままではアプリを入れられません。

Chrome で開く

  1. 1

    アプリをダウンロード

    アプリをダウンロード

    「悪影響を及ぼす可能性があります」と出たら、「ダウンロード」を押してください。Google の定型の確認で、異常ではありません。

  2. 2

    ダウンロードしたファイルを開く

    画面の上に出る通知 kubiraku.apk をタップします。これがアプリのファイルです。

    通知が見つからないときは、Chrome 右上の ⋮ → ダウンロード から開けます。「もう一度ダウンロードしますか？」と出たら キャンセルし、一覧のファイルを開いてください。

  3. 3

    「インストール」を押す

    「デバイスを保護するため…」と出ても大丈夫です。小さい文字の 詳細 → インストールする を押します。

    デバイスを保護するため
    アプリをブロックしました

    ここを押す：詳細 → インストールする OK（押さない）

    大きい OK は「やめる」なので押さないでください。「この提供元のアプリを許可」と出たら、スイッチをオンにして戻ります。

終わったら、ホーム画面の 首らく を開き、「見守りを始める」で通知を許可してください。画面上に「首らくが見守っています」が出ていれば、ほかのアプリを開いていても測れます。

うまくいかないとき

「この提供元を許可」の画面が出なかったときは、ここから許可できます。

インストールの許可を開く

手動で行う場合：設定 → アプリ → Chrome → 不明なアプリのインストール → オン

測定がすぐ止まるときは、アプリの設定で「電池の最適化を解除」を押してください。

カメラは使いません。記録はこの端末の中だけに残ります。医療機関ではなく、診断や治療のためのアプリではありません。
